# Документы

Документ — это текст, который слишком длинный, чтобы раскладывать его целиком: лог, книга, файл на 200 000 строк. Lettera держит его исходник в `LetteraRope`, дереве блоков, и раскладывает только **окно** рядом с видимой частью. Прокрутка внутри окна двигает глифы без перестроения, прокрутка за его край переносит окно.

[English version](Documents.md) · Другие руководства: [Getting Started](GettingStarted.ru.md), [Fields](Fields.ru.md), [Motion](Motion.ru.md), [Tools](Tools.ru.md)

## Нужен ли он вам

Обычный `LetteraText` и сам справляется с длинным текстом: сначала формирует абзацы рядом с видимым, остальное доделывает в следующих кадрах и расставляет глифы только на строках возле экрана (см. [Длинный текст без документа](#длинный-текст-без-документа)). Документ нужен, когда:

- текст весит мегабайты или лежит в файле, который не хочется читать в строку;
- он должен плавно прокручиваться при любой длине, с полосой прокрутки;
- его нужно искать, листать переходами или редактировать, не держа целиком в `string`.

## Открыть документ

**GameObject > Lettera > Document** создаёт текст на Canvas внутри прокрутки, готовый к заполнению. Из кода:

```csharp
// Файл: отображается в память, где платформа это позволяет, и декодируется только при чтении.
text.OpenDocument(LetteraFileSource.Load(path), takeOwnership: true);

// Текст, который уже у вас в руках.
text.OpenDocument(LetteraRope.FromString("Первая строка\nВторая строка"), takeOwnership: true);
```

- `takeOwnership: true` поручает тексту освободить rope, когда документ закроется. `text.CloseDocument()` возвращает текст к его собственному значению.
- `text.Document` — это сам rope, `text.View` — положение окна.
- Файл может быть в UTF-8, UTF-16 или UTF-32, с меткой порядка байтов или без. `LetteraFileOptions` задаёт кодировку и способ чтения (`Mapped`, `Chunked` или `InMemory`). В вебе файл читается в память.
- Разметка работает как в любом тексте. Тег, открытый в первой строке, действует и через тысячи строк, где бы ни стояло окно.
- Выделение, диапазоны, ссылки и анимация работают внутри окна как в обычном тексте.

### Из инспектора: Source Loader

**Source Loader** на объекте текста открывает документ из файла, `TextAsset` или по адресу в сети, когда объект включается. Неудачная или отменённая загрузка оставляет текст как был.

```csharp
var loader = text.gameObject.AddComponent<LetteraSourceLoader>();
loader.Source = new LetteraPathSource { Root = LetteraPathRoot.StreamingAssets, Path = "Books/whale.txt" };
loader.Loaded += () => Debug.Log("Книга открыта");
loader.Failed += error => Debug.LogWarning(error);
loader.Reload();
```

`LetteraTextAssetSource` читает `TextAsset`, `LetteraUrlTextSource` — адрес. `Progress` и `IsLoading` показывают, как далеко зашла загрузка; `Cancel()` её останавливает.

## Прокрутка

`LetteraDocumentScroller` — это область просмотра: поставьте его на `RectTransform`, а текст пусть заполняет её. Ни то ни другое не растёт до размера документа.

```csharp
var scroller = scrollerObject.AddComponent<LetteraDocumentScroller>();
scroller.Text = text;
scroller.StickToEnd = true;     // Лог: держится у конца, пока приходят строки.
scroller.ScrollToEnd();
```

Он понимает перетаскивание, колесо, инерцию и упругие края и управляет `Scrollbar` (`VerticalScrollbar`). `PassWheelAtEdges` отдаёт колесо внешней прокрутке, когда документ дошёл до края. Работает он и на обычном тексте на Canvas, который не документ.

Переходы из кода идут через view. Позиции считаются в символах исходника, вместе с разметкой:

```csharp
text.View.ScrollToParagraph(1000);
text.View.ScrollToChar(52000, LetteraRevealAlign.Center);
text.View.PositionChanged += () => Debug.Log(text.View.DocumentY + " из " + text.View.MaxDocumentY);
```

Высоты сначала оценочные и измеряются в фоне. Если высота выше видимой части оказалась другой, под взглядом ничего не сдвигается: вид привязан к символу, а не к пикселю. Пока тянут ручку полосы прокрутки, `FreezeExtent` держит её показания неподвижными.

## Поиск

`LetteraDocumentSearch` читает документ порциями, так что ни один кадр его не ждёт. Запускайте его в корутине:

```csharp
using System.Collections;

IEnumerator Find(string query)
{
    var search = new LetteraDocumentSearch(text.Document) { Query = query, Comparison = StringComparison.OrdinalIgnoreCase };
    var hits = new List<LetteraSearchHit>();
    search.Start();
    while (search.Step(2, hits)) yield return null;    // Около 2 мс за кадр.
    if (hits.Count > 0) text.View.ScrollToSpan(hits[0].Start, hits[0].End, LetteraRevealAlign.Center);
}
StartCoroutine(Find("кит"));
```

- `Scope = LetteraSearchScope.Shown` ищет в том, что видит читатель, поэтому слово, разорванное тегом, остаётся одним словом; `Source`, вариант по умолчанию, ищет в исходнике как он написан.
- Находки — это символы исходника. `Progress` показывает, сколько прочитано; `Cancel()` останавливает поиск.
- `text.FindAll(query, hits, ignoreCase)` на документе читает весь документ тем же поиском и возвращает символы исходника.

## Редактирование

`LetteraEditable` на том же тексте редактирует документ: ввод, удаление, буфер обмена и отмену, которая возвращает к месту правки. Выделение хранится в символах исходника, поэтому оно не теряется при движении окна и следует за правками. О самом поле — в [Fields](Fields.ru.md).

## Слишком мелкий текст

Документ, нарисованный мельче 4 экранных пикселей на em, рисует полоски вместо глифов, как мини-карта. `text.View.BarsEnabled` это выключает, а `MinLegiblePixelsPerEm` двигает порог. `IsShownAsBars` говорит, что сейчас на экране.

## Тайский, лаосский, кхмерский и бирманский

В этих письменностях слова пишутся без пробелов, поэтому строки переносятся, а двойной щелчок выделяет по списку слов. В пакете четыре списка, собранных из списков ICU: **Thai Words**, **Lao Words**, **Khmer Words** и **Myanmar Words**.

- По умолчанию ни один не подключён, и в сборку ничего не добавляется. Нужные укажите в **Project Settings > Lettera > Defaults > Dictionaries**.
- Или подключите из скрипта: `LetteraWordDictionaries.Register(dictionary)`.
- Свой словарь: **Assets > Create > Lettera > Word Dictionary**, затем **Build From A Word List…** в его инспекторе: по слову в строке, `#` для комментариев.
- Анимации по словам и `text.Units(LetteraTextUnit.Word)` считают те же слова в любом тексте, документ он или нет.

## Настройки

**Project Settings > Lettera > Documents**, читаются при открытии документа:

| Настройка | По умолчанию | Что делает |
|---|---|---|
| Margin Viewports | 0.5 | Насколько окно выходит за область просмотра, в её высотах |
| Edge Viewports | 0.25 | Окно сдвигается, когда видимое подходит к его краю на это расстояние |
| Max Window Codepoints | 14 000 | Наибольший размер окна, чтобы его меш помещался в то, что может нарисовать Canvas |
| Scan Budget Ms | 1 | Время за кадр на поиск открытых тегов и измерение |
| Measure In Background | вкл. | Измеряет высоты между кадрами, а не по запросу |

## Длинный текст без документа

Обычный длинный текст, примерно от 4096 глифов, тоже работает только там, где его видно:

- Он расставляет и рисует глифы только на строках в пределах половины экрана от того, что показывают его корневой канвас и любой `RectMask2D`. Прокрутка дальше расставляет новые строки до отрисовки этого же кадра.
- Когда текст задан, сразу формируются и разбиваются на строки только первые абзацы и те, что рядом с видимым. Остальные стоят с оценённой высотой и доделываются в следующих кадрах, около 2 мс за кадр, по порядку чтения.
- До тех пор его высота, предпочтительная высота для раскладки и, значит, полоса прокрутки — оценки и могут сдвигаться. `IsFinishing` говорит об этом, а `FinishNow()` доделывает сразу.
- `Lines`, каретка, выделение, попадания, ссылки и измерения сначала доделывают всё, поэтому точны в любом месте. `GlyphCount`, `GetGlyph` и `InkBounds` охватывают расставленные строки.
- Правка простого текста переделывает только абзацы начиная с затронутого.

Всё это задаёт `LetteraLongText`:

```csharp
LetteraLongText.FromGlyphs = 8192;                 // С какой длины расставляется только видимое.
LetteraLongText.FinishMillisecondsPerFrame = 1;    // Меньшая доля кадра на доделку.
LetteraLongText.FinishLater = false;               // Сформировать и разбить всё сразу.
```

## Ограничения

- Правка выделения, которое выходит за пределы окна, отклоняется целиком с одним предупреждением, чтобы ничего не удалилось наполовину: «выделить всё и удалить» в документе пока не работает. Копирование такого выделения работает.
- Правило поля, которому нужно всё значение, читает окно. `Source` у документа возвращает исходник окна, а `Length` и `PlainText` отвечают за окно.
- `AutoSize` показывает документ в наименьшем размере, многоточие не применяется.
- Окно текста в мире следует `View`, и его ничто не обрезает: области просмотра на камере для текста в мире нет. Текст с окном внутри `ScrollRect` не отвергается, хотя должен бы. Номера списков не переходят через край окна. Скруглённые концы диапазонов, разрезанных окном, не рисуются.
- Каждое нажатие клавиши в документе заново разбирает окно. Один длинный абзац при нажатии формируется целиком.
- Списка слов для китайского и японского в пакете нет; проект может собрать свой. Встроенные списки проверены на нескольких предложениях каждой письменности, а не на корпусе против результатов ICU.
- Номера уравнений в документе считаются в пределах окна, поэтому после прокрутки то же уравнение может получить другой номер. `longtable` — один объект и не делится между окнами. Обход текста по единицам считает окно.
- Облегчённое окно, которое строит резкая прокрутка, обгоняющая поля окна, ставится по оценкам документа: строка наверху стоит там, куда её ставят высоты ещё не измеренных блоков. Размер ручки прокрутки уточняется, когда прокрутка останавливается.
- Пока длинный текст не доделан, его глифов нет целиком: `GlyphCount`, `GetGlyph`, `InkBounds` и меш охватывают только расставленные строки. Под маской-трафаретом `Mask` полосой считается весь канвас, а канвас в мире без `RectMask2D` расставляет всё. Текст с дугой, бегущей строкой, появлением, инлайн-объектом или обработчиком стадии расставляет всё.
- Абзацы на потом оставляет только длинный текст, выровненный по верху, без эффектов раскладки, авторазмера и многоточия. Текст, который ждёт только невидимых абзацев, стоит около 2 мс за кадр, пока не доделан.
