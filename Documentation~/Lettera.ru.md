# Lettera

[English version](Lettera.md)

Lettera — движок текста для Unity. Он рисует текст на Canvas, в мировом пространстве и объёмной 3D-геометрией и читает любую письменность так же, как браузер: шейпинг OpenType через HarfBuzz, строки справа налево и со смешанным направлением, переносы и кластеры по правилам Unicode, цветные эмодзи. Если шрифт не назначен, текст берёт шрифты самой операционной системы, так что арабский, хинди, китайский и эмодзи работают даже в пустом проекте.

Как выглядит участок текста, задаёт разметка. Тег что-то значит только потому, что стиль связывает его с эффектом, и словарь по умолчанию уже связывает больше шестидесяти тегов: насыщенность, цвет, градиенты, обводки, тени, движение, ссылки, формулы. Можно добавить свои теги или находить участки иначе — например, по Markdown или по `@упоминаниям`.

Кроме того:

- **Поля.** Любой текст можно выделять, и любой текст может стать полем ввода с правилами того, что в него попадает.
- **Движение.** Текст, который колышется, печатается сам или отвечает на указатель — без перестройки и без выделения памяти в кадре.
- **Документы.** Текст любой длины через одно окно рядом с видимой областью.
- **Формулы.** Подмножество TeX прямо в предложении и таблицы LaTeX.
- **3D-текст.** Настоящая освещённая геометрия с фасками — для логотипов и заголовков.

## Установка

Откройте **Window > Package Manager**, нажмите **+**, выберите **Add package from git URL...** и вставьте:

```text
https://github.com/FirstSymbol/lettera-unity.git
```

Чтобы закрепить версию, добавьте её тег:

```text
https://github.com/FirstSymbol/lettera-unity.git#1.0.0
```

Нужен Unity 6.3 LTS (6000.3) или новее. Зависимости (uGUI, Burst, Collections, Mathematics) Package Manager подтянет сам. При первом открытии проекта в консоли появится одна строка со ссылкой на **Tools > FirstSymbol > Lettera > Getting Started**: там список этих руководств и импорт примеров.

## Пять минут

**1. Текст на экране.** В Hierarchy выберите **GameObject > Lettera > Text**. Если в сцене нет Canvas и EventSystem, Lettera создаст их. Впишите в поле **Text** инспектора:

```text
Hello, <b>world</b> · مرحبا · 你好 👋
```

Все письменности и эмодзи появятся сразу, из шрифтов системы.

**2. Текст из скрипта.** Добавьте этот компонент рядом с текстом и нажмите Play:

```csharp
using FirstSymbol.Lettera;
using UnityEngine;

public class IndexScore : MonoBehaviour
{
    LetteraText m_Label;
    int m_Score;
    float m_Next;

    void Start()
    {
        m_Label = GetComponent<LetteraText>();
        m_Label.FontSize = 36;
        m_Label.Text = "<b>Score</b>: <color=#FC0>0</color>";
    }

    void Update()
    {
        if (Time.time < m_Next) return;
        m_Next = Time.time + 0.5f;
        m_Label.SetText("Score: " + ++m_Score);
    }
}
```

`Text` — сохраняемое значение. `SetText` — для значений, которые меняются во время игры: сохранённый текст он не трогает, а символы, которые текст уже показывал, ничего нового не стоят.

**3. Свой шрифт.** Выделите файл `.ttf`, `.otf` или `.ttc` в окне Project и выберите **Assets > Create > Lettera > Font Asset From Selection**. Перетащите новый ассет в поле **Font** текста. Символы, которых в шрифте нет, по-прежнему придут из системы.

**4. Внешний вид.** Напишите `<stroke=#000,0.08><shadow=#0008,0.05,-0.05>Title</shadow></stroke>` или откройте в инспекторе карточку **Styles**, нажмите **+ Add Style** и выберите **Fill**, а затем градиент.

**5. Движение.** Напишите `<wave>hello</wave>`. Текст двигается в Play mode, а в режиме редактирования — после **Preview Motion** в карточке Interaction инспектора.

Дальше [Первые шаги](GettingStarted.ru.md) проходят тот же путь подробнее, по одной задаче за раз.
