# Lettera

Текстовый движок для Unity UI и мирового пространства: полный шейпинг OpenType, двунаправленный текст, перенос строк по Unicode, системные шрифты с автоматическим fallback, цветные эмодзи, общий SDF-атлас и стили на расширяемой разметке.

[English version](README.md)

```csharp
label.Text = "Hello · مرحبا بالعالم · שלום · 👨‍👩‍👧‍👦";
```

Файлы шрифтов не нужны: если ничего не назначено, текст использует шрифт ОС по умолчанию, а недостающие символы берёт из других шрифтов системы.

## Установка

Unity Package Manager → **+** → **Add package from git URL...**:

```
https://github.com/FirstSymbol/lettera-unity.git
```

Конкретная версия:

```
https://github.com/FirstSymbol/lettera-unity.git#0.1.0
```

Нужен Unity 6 (6000.0) или новее.

## Быстрый старт

- **GameObject → Lettera → Text** создаёт текст на Canvas.
- **GameObject → Lettera → World Text** создаёт текст в мировом пространстве, без Canvas.
- Чтобы использовать свой шрифт, выберите файл `.ttf`, `.otf` или `.ttc` и нажмите **Assets → Create → Lettera → Font Asset From Selection**.

```csharp
using FirstSymbol.Lettera;

label.Text = "<b>Счёт</b>: <color=#FC0>10</color>";
label.SetText("Счёт: 11");      // Текст времени выполнения; те же символы повторно ничего не стоят.
label.FontSize = 24;
label.AutoSize = true;
label.Overflow = LetteraOverflow.Ellipsis;
Vector2 size = label.MeasureText(new LetteraMeasureOptions { MaxWidth = 300 });
```

## Разметка

Тег что-то значит, только если стиль связывает его с эффектом; тег, который никто не занял, остаётся обычным текстом. Встроенный словарь действует, пока проект не назначит свой глобальный пресет стилей, а **Use Global Style Preset** отключает его для отдельного текста.

| `<i>`, `<em>` | Курсив | наклон в процентах от высоты глифа |

| `<ruby>`, `<rt>`, `<rp>` | Чтения над текстом | `<ruby=чтение>` или `<rt>` |
| `<tracking>`, `<word-spacing>` | Интервалы | локальные единицы или `em` |
| `<cell>` | Ячейки равной ширины | ширина или `auto` |

Свой тег — это стиль в тексте или пресете:

```csharp
label.Styles.Add(LetteraStyle.ForTag(new ColorEffect(), "warning", "#FF8800"));
label.MarkStylesDirty();
```

Собственное поведение наследуется от `LetteraEffect` (как выглядит диапазон) и `LetteraMatcher` (как диапазоны находятся).

## Стили

Любая цветная поверхность принимает краску: цвет, градиент или текстуру. Стили собираются на вкладке **Styles** инспектора, где **+ Add Style** предлагает всё по способу запуска и назначению, или в коде:

```csharp
var fill = new FillEffect();
fill.SetPaint(LetteraPaint.Of(LetteraGradient.Of(orange, pink, blue), LetteraPaintSpan.Range));
label.Styles.Add(LetteraStyle.ForTag(fill, "sunset"));
label.MarkStylesDirty();
label.Text = "<sunset>Градиент на весь диапазон</sunset>";
```

Градиент с охватом **Range** идёт через всё предложение, с **Glyph** или **Line** начинается заново. Сплошная краска и градиент никогда не разбивают батч; текстура или смешивание не `Normal` получают свой материал, порядок при этом сохраняется.

Слои рисуются полосами: тень и свечение, обводка, лицо, внутренняя тень. Внутри полосы более поздние стили лежат сверху. Фильтр действует на то, что ниже него в списке стилей, и на лицо глифа, поэтому фильтр последним в списке перекрашивает всё.

Параметр меняется по цене своего уровня, без разбора разметки:

```csharp
stroke.Width = 0.05f;
label.MarkEffectsDirty();          // По умолчанию уровень меша.

LetteraHold<Color32> hold = label.Ranges(color).WithLabel("warn").Hold<Color32>(0);
hold.Value = red;                  // Все диапазоны <color #warn=...>, поле эффекта не меняется.
hold.Release();                    // Снова как в разметке.
```

Несколько эффектов живут в одном стиле через `CompositeEffect`: значение тега делится точкой с запятой, по сегменту на дочерний эффект: `<badge=(mailto:a@b.io);teal;wavy>`. Чтобы использовать повторно, сохраните его как ассет пресета эффекта.

**Диапазоны находятся не только по тегам:** Markdown (`**жирный**`, `- списки`, `[ссылки](url)`, `` `код` ``), голые URL, слова с триггером вроде `@упоминаний`, буквальные строки. В словаре по умолчанию их нет, потому что они меняют обычный текст: добавляйте через пикер.

**MSDF:** выберите в **Render Mode** значение MSDF, чтобы получить острые углы на любом размере ценой памяти атласа. **Пиксельные шрифты:** задайте у ассета шрифта **Pixels Per Em** или нажмите **Find Pixel Grid**; на кратных сетке размерах каждый пиксель шрифта точен, а эффекты идут целыми пикселями шрифта.

**Свой эффект:** **Assets → Create → Lettera → Custom Effect** создаёт шейдер с одной функцией для правки, для стиля **Custom Material**. Он работает на Canvas и в мировом тексте, на Built-in и Universal.

## Выделение и редактирование

```csharp
gameObject.AddComponent<LetteraSelectable>();           // выделять и копировать
var field = gameObject.AddComponent<LetteraEditable>(); // и редактировать
field.AddRule(new SingleLineRule());
field.AddRule(new MaxLengthRule { Limit = 40 });
field.Submitted += value => Debug.Log(value);
```

**GameObject > Lettera** создаёт поле ввода, текстовую область, поле пароля, выпадающий список, выделяемый или редактируемый текст. Пример Fields собирает их все из кода.

- Значение поля — это исходный текст вместе с разметкой: `field.Source`. `field.PlainText` — значение без разметки, а `CopyTo` и `Equals` читают его без аллокаций.
- Правила держат политику и работают в порядке списка. Фильтр судит о том, что правка оставит после себя, валидатор только сообщает, а декоратор показывает состояние на интерфейсе, который вы назначите.
- Команды вроде `field.ToggleEffect<BoldEffect>()` пишут в синтаксисе самого поля, и им нужен стиль с этим эффектом: сами они стилей не добавляют.
- Тексту в мире нужен `LetteraWorldRaycaster` на камере, а любому тексту — `EventSystem` с модулем ввода.
- Под Canvas Group с выключенным interactable выделяемый текст и поле не принимают нажатий: ни каретки, ни выделения, ни меню, а перетаскивание уходит к прокрутке вокруг. `IsInteractable` говорит, так ли это.
- `text.Units(LetteraTextUnit.Word)` обходит кластеры, слова (по UAX #29 и установленным словарям), строки или абзацы того, что показывает текст, целиком или в диапазоне, а `CountUnits` их считает, и оба без аллокаций. `FindAll` находит все места, где стоит строка, с учётом регистра или без.
- До ОС всё доходит через `ILetteraInputSource` и `ILetteraClipboardBackend`, которые можно заменить.

## Анимация и интерактив

```
<wave>движется без перестроения</wave>  <shake>дрожит</shake>  <roll>1234</roll>
<a=https://unity.com>ссылка</a>  <spoiler>секрет под обложкой</spoiler>  <sprite=star>
```

- **Анимация** работает через проход поз: без перестроения и без аллокаций за кадр. `RevealEffect` работает как печатная машинка, `MarqueeEffect` как бегущая строка.
- **`LetteraSequencer`** плавно меняет любой параметр эффекта на таймлайне, а его `Progress` можно вести кривой. **Tools > Lettera > Sequencer** показывает его реплики на дорожках: их можно двигать, делить и копировать. `LetteraParamLink` даёт одному параметру поле для анимации. Дорожки Timeline появляются, когда установлен этот пакет.
- **Диапазоны** реагируют на указатель и клавиатуру: `LetteraRangeRouter.Of(text).All.Activated += e => Debug.Log(e.Primary);`. Ссылки открываются только со схемами из списка `LetteraSettings.Motion.LinkSchemes`.
- **`LetteraRangeRule`** меняет параметры при наведении, нажатии или фокусе. **Инлайн-элементы** берутся из `InlineEffect` или `LetteraInlineLibrary`. **`LetteraSemanticTree`** описывает диапазоны для моста к экранным дикторам. Эффекты могут участвовать в любой стадии перестроения через `Stages`.
- `LetteraAccessibility.ReducedMotion` учитывается везде, а в вебе следует настройке браузера.

## Документы

```csharp
text.OpenDocument(LetteraFileSource.Load(path), takeOwnership: true);   // Или LetteraRope.FromString(...), или компонент Source Loader.
scrollerObject.AddComponent<LetteraDocumentScroller>().Text = text;
text.View.ScrollToParagraph(1000);
```

- Размечается только то, что рядом с видимой областью, а прокрутка внутри неё обходится без перестроения. Файл отображается в память и декодируется только при чтении.
- `LetteraEditable` на том же тексте редактирует документ. `LetteraDocumentSearch` ищет текст порциями, не занимая кадр целиком.
- Тайский, лаосский, кхмерский и бирманский переносятся по словам, когда `LetteraWordDictionary` указан в настройках проекта. По умолчанию словарей нет, и в сборку они не попадают.
- **Длинный текст без документа** расставляет и рисует глифы только на строках рядом с тем, что показывают его канвас и маски; прокрутка за их пределы расставляет новые строки до отрисовки этого же кадра. Когда текст задан, сразу формируются и разбиваются на строки только первые абзацы и те, что рядом с видимым; остальные стоят с оценённой высотой и доделываются в следующих кадрах, около 2 мс за кадр (`LetteraLongText.FinishMillisecondsPerFrame`), по порядку чтения. До тех пор его высота, предпочтительная высота для раскладки и, значит, полоса прокрутки — оценки и могут сдвигаться; `IsFinishing` говорит об этом, а `FinishNow()` доделывает сразу. `Lines`, каретка, выделение, попадания, ссылки и измерения сначала доделывают всё, поэтому точны в любом месте. Правка простого текста переделывает только абзацы начиная с затронутого. `GlyphCount`, `GetGlyph` и `InkBounds` охватывают расставленные строки. `LetteraLongText` выключает любую из частей или задаёт, с какой длины она начинается. Окно документа тоже расставляет только строки рядом со своей областью просмотра; при прокрутке быстрее, чем достают его поля, оно держит и расставляет только видимое и возвращает поля через два кадра после остановки.

## Формулы

```csharp
label.Text = "Энергия это <math>E = mc^2</math>, а <math=display>\\sum_{i=0}^n i = \\frac{n(n+1)}{2}</math> стоит отдельно.";
```

- Формула пишется на линейном подмножестве TeX внутри `<math>`. `<math=display>` выносит её в отдельный абзац. `<math=inline,x в квадрате>x^2</math>` даёт ей слова для экранного диктора.
- **Команды:** дроби и биномы, корни, индексы и пределы, большие операторы, `\left \right` и разделители заданного размера, акценты, черты, скобки, стрелки, матрицы, `cases`, `aligned`, `array`, `\text`, отступы, `\color`, алфавиты вроде `\mathbb` и около 475 символов. Макросов, `\def` и `\ce` нет.
- Формула, которую нельзя прочитать, рисует написанное в рамке, а текст вокруг остаётся. `LetteraMath.Validate` проверяет формулу, а `LetteraMath.Failed` сообщает о каждой такой.
- **Номера уравнений.** В `<math=display>` окружения `align`, `gather`, `equation` и `multline` нумеруют себя сами, (1), (2) и дальше, со счётом в пределах текста. `\tag{x}` ставит метку на место номера, `\tag*{x}` убирает у неё скобки, `\notag` или `\nonumber` оставляет строку без номера, а `\setcounter{equation}{n}` делает следующий номер равным n + 1. Номер стоит у правого края строки, в тексте справа налево у левого, по середине своей строки; `LetteraFormulaInfo.Tags` их перечисляет.
- Формула это один объект в строке: она не переносится, выделяется, копируется и удаляется целиком. Цвет, размер, прозрачность, обводка, тень, свечение и движение действуют на неё как на текст, и движется она как одно целое.
- При копировании обычным текстом идёт `$исходник$`, в HTML идёт MathML с исходником, а в поле Lettera идёт сам тег.
- **Какой шрифт.** По порядку: `LetteraMathEffect.Font` у стиля, `LetteraSettings.Math.Font` у проекта, шрифт текста, если в нём есть таблица MATH, системный математический шрифт (Cambria Math на Windows; в web, на Android и iOS его нет), и в конце шрифт текста с запасной вёрсткой, читаемой, но простой.
- **Встроенный шрифт.** Noto Sans Math лежит в пакете и попадает в сборку, только если на него кто-то ссылается. **Lettera > Math > Use Bundled Font** задаёт его всему проекту, это 343 КБ в каждой сборке. На стиле он стоит места только там, где этот стиль используется. Сборка для web, Android или iOS предупреждает, если в сцене есть формула, а шрифт не задан. Подойдёт любой шрифт с таблицей MATH: STIX Two Math и Latin Modern Math выглядят классичнее.
- `LETTERA_NO_MATH` убирает формулы из компиляции. Тогда `<math>x</math>` показывает `x`.

## 3D-текст

```csharp
LetteraText3D solid = go.AddComponent<LetteraText3D>();    // Или GameObject > Lettera > Text 3D.
solid.Text = "Solid <wave>Text</wave>";
solid.Depth = 0.25f;
solid.FrontBevel = new LetteraBevel { Shape = LetteraBevelShape.Round, Width = 0.03f, Height = 0.03f, Roundness = 0.5f, Segments = 4 };
```

- Настоящая геометрия со светом и тенями, которую рисует собственный `MeshRenderer` объекта: девять форм кромки и своя кривая, пять слотов материалов с запасными вариантами друг для друга и шейдер `Lettera/Solid Lit` для Built-in, URP и HDRP, где он проходит через собственный цикл освещения конвейера. Мировой текст под HDRP тоже рисуется, с освещением и без.
- Разметка, шрифты, резервные шрифты, двунаправленный текст, арабский и индийский шейпинг, перенос и автоподбор размера те же, что у мирового текста. Движение тоже: все анимации двигают тела, а затухание идёт через экранный дизеринг, поэтому сортировка не нужна.
- Каждый глиф строится один раз при любой глубине текста и общий для всех текстов с теми же шрифтом и кромками. Одинаковые тексты делят один меш, поэтому могут идти через инстансинг.
- `<depth=2>` и `<bevel=chamfer,0.03,0.03>` действуют на диапазон. `LetteraSolidLook` хранит глубину, кромки, материалы и слои, чтобы задать их разом.
- **Слои** — дополнительные тела вокруг глифа, слова, строки или всего текста: расширенный или суженный контур, пластина со скруглёнными углами или неоновая трубка вдоль каждого контура; полосой, с буквами насквозь или гравировкой; у каждого свои глубина, кромка, цвет и материалы. `solid.AddLayer(LetteraSolidLayer.Preset(LetteraSolidLayerPreset.Badge))`.
- **Деформаторы** изгибают (360 градусов дают кольцо), скручивают, сужают, пускают волной, натягивают на шар или ведут по пути, по порядку, и уносят с собой слои и подчёркивания: `solid.AddDeformer(LetteraDeformer.Bend(360))`. Диапазон получает свой: `<bend=90>`, `<twist=180>`, `<taper=0.5>`, `<ripple=0.1,1.5>`, `<sphere=120>`.
- Подчёркивание и зачёркивание выдавливаются. Формулы тоже, с чертами в виде брусков. Цветной глиф рисуется плоско на передней плоскости или не рисуется совсем.
- **Чего нет:** 2D-слои (обводка, тень, свечение) на теле не рисуются. Нет выделения и редактирования.
- **На Canvas.** Это не Graphic, потому что на Canvas нет света: текст рисуется как объект сцены, без масок и вёрстки, а под Screen Space Overlay не виден совсем. Для 3D-текста в интерфейсе направьте на него камеру с `RenderTexture` и покажите её в `RawImage`. Так сделано в сэмпле 3D.
- **В сборке.** Компонент в сцене приносит свой материал и шейдер. В сборке без него нет ни того, ни другого. Тексту из скрипта без материала нужен **Lettera > 3D > Allow Creating From Scripts**, и шейдер тогда будет в каждой сборке. `LETTERA_NO_3D` убирает модуль.
- В контекстном меню есть **Bake To Mesh Asset** и **Export OBJ**, а у мирового текста есть **Convert To Text 3D**.

| macOS universal | собран | да |

Что и на чём проверено, смотрите в [истории изменений](CHANGELOG.md).

### Web

Браузеры не дают доступа к файлам шрифтов, поэтому на web:

- Текст без шрифта использует встроенный Noto Sans: латиница, кириллица и греческий. **Остальные письменности показывают квадраты, пока вы не назначите шрифт**, который их покрывает, через **Font** или **Font Stack**. После этого шейпинг работает как везде.
- Эмодзи рисует Canvas браузера, поэтому они выглядят как эмодзи этого устройства. Цвет и прозрачность применяются как обычно.
- `LetteraSettings.WebGLFallbackFont` заменяет встроенный шрифт.
- Память под глифы ограничена сильнее, чем на других платформах: при достижении лимита используется заново страница атласа, к которой дольше всего не обращались.

### Нативная платформа

Поля, буфер обмена и меню могут работать через собственные элементы платформы. У каждой части есть переключатель в Project Settings > Lettera > Native Platform, и там сказано, почему она включена или выключена на текущей платформе сборки.

| | Windows | Web | Android, iOS | macOS |
|---|---|---|---|---|
| Ввод текста | композиция через метод ввода | одно текстовое поле, композиция в строке | выключен, пока не включите | средствами Unity |
| Буфер обмена с форматами | включён | включён | выключен, пока не включите | выключен, пока не включите |
| Реплика (`ReplicaFieldRule`) | не действует | включена, если поле просит | выключена, пока не включите | не действует |
| Шрифты отдельными файлами рядом со сборкой | включено | нет | внутри ассета | включено |
| COLRv1 | включён | включён | включён, на устройстве ещё не проверен | включён, на устройстве ещё не проверен |

Всё, что ещё не запускалось на настоящем устройстве, по умолчанию выключено. Сэмпл Device Check проводит по устройству экран за экраном и выдаёт один блок текста с результатами: **Lettera > Device Check > Build for...** включает всё это только для этой сборки.

```csharp
// Вставка работает везде через команду. В браузере буфер обмена читается только с задержкой.
new PasteCommand().Execute(new LetteraCommandContext(field.Selectable));
field.PasteAsync();

// Сколько сейчас стоят шрифты.
LetteraFontMemory.Sums sums = LetteraFontMemory.Totals;
```

После обновления редактор держит загруженную нативную библиотеку до перезапуска: COLRv1 ждёт его, всё остальное работает.

## Сэмплы

В **Window > Package Manager > Lettera > Samples**. Каждый собирается из кода: добавьте его компонент на пустой объект в пустой сцене и нажмите Play.

- **Basic:** разные письменности, эмодзи, теги, перенос, многоточие, авторазмер и текст из кода, без единого шрифта в проекте.
- **Fields:** чат, поле e-mail с проверкой, пароль, поле с форматированием, выпадающий список и выделяемый текст.
- **Motion:** все анимации, печатная машинка, бегущая строка, ссылка, спойлер, правило на наведение и спрайт в тексте.
- **Documents:** 200 000 строк в прокрутке, с поиском и переходом к найденному.
- **Math:** формулы в строке и отдельно, каждая конструкция рядом с исходником, поле, показывающее набранное. В вебе назначьте шрифт.
- **3D Text:** по строке на каждую форму фаски, все материалы, формула, пластина, неон, скрутка и кольцо, 500 одинаковых надписей и объёмный текст в Canvas. Назначьте материал с шейдером Lettera/Solid Lit.
- **Device Check:** один проход по устройству с подсказками и один блок текста, который можно скопировать или отправить.
- **Emoji:** флаги, составные эмодзи, цвета кожи, кнопки с цифрами, прозрачность и цвет, и маленький цветной шрифт в комплекте.
- **Layout:** один блок текста и живые настройки: выравнивание, перенос, переполнение, авторазмер, высота строки, обрезка, дуга и отступы.
- **Fonts:** системные шрифты, стек, вариативная ось, возможности OpenType, пиксельный шрифт и шрифт иконок, всё из кода.
- **Styles:** галерея рядом со своей разметкой: все слои, градиенты, фильтры, пресеты, свой тег и эффект со своим шейдером.
- **Rich Editor:** страница текстового редактора: панель следит за кареткой, привычные клавиши, вставка сохраняет форматирование.
- **Timeline:** нужен пакет Timeline. Катсцена из кода: реплика, которую печатает клип, секвенсор и связанный параметр на трёх дорожках.

## Пересборка нативного плагина

`Native~/build.py` собирает HarfBuzz и обёртку на C для всех платформ с помощью [zig](https://ziglang.org), а Android — с помощью NDK из модуля Android в Unity. Шейпинг выполняет [HarfBuzz](https://harfbuzz.github.io), собранный из исходников в `Native~/third_party`; см. [сторонние лицензии](THIRD-PARTY-NOTICES.md). Библиотеки для iOS и web линкуются статически, поэтому символы HarfBuzz в них переименованы, чтобы не конфликтовать с копией в web-плеере Unity.
