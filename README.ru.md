# Lettera

Текстовый движок для Unity UI и мирового пространства: полный шейпинг OpenType, двунаправленный текст, перенос строк по Unicode, системные шрифты с автоматическим fallback, цветные эмодзи, общий SDF-атлас и стили на расширяемой разметке.

[English version](README.md)

```csharp
label.Text = "Hello · مرحبا بالعالم · שלום · 👨‍👩‍👧‍👦";
```

Файлы шрифтов не нужны: если ничего не назначено, текст использует шрифт ОС по умолчанию, а недостающие символы берёт из других шрифтов системы.

## Установка

Unity Package Manager → **+** → **Add package from git URL...**:

```
https://github.com/FirstSymbol/lettera-unity.git
```

Конкретная версия:

```
https://github.com/FirstSymbol/lettera-unity.git#0.1.0
```

Нужен Unity 6 (6000.0) или новее.

## Быстрый старт

- **GameObject → Lettera → Text** создаёт текст на Canvas.
- **GameObject → Lettera → World Text** создаёт текст в мировом пространстве, без Canvas.
- Чтобы использовать свой шрифт, выберите файл `.ttf`, `.otf` или `.ttc` и нажмите **Assets → Create → Lettera → Font Asset From Selection**.

```csharp
using FirstSymbol.Lettera;

label.Text = "<b>Счёт</b>: <color=#FC0>10</color>";
label.SetText("Счёт: 11");      // Текст времени выполнения; те же символы повторно ничего не стоят.
label.FontSize = 24;
label.AutoSize = true;
label.Overflow = LetteraOverflow.Ellipsis;
Vector2 size = label.MeasureText(new LetteraMeasureOptions { MaxWidth = 300 });
```

## Разметка

Тег что-то значит, только если стиль связывает его с эффектом; тег, который никто не занял, остаётся обычным текстом. Встроенный словарь действует, пока проект не назначит свой глобальный пресет стилей, а **Use Global Style Preset** отключает его для отдельного текста.

| Тег | Эффект | Параметры |
|---|---|---|
| `<b>`, `<strong>` | Насыщенность | вес 100-900; `f` — только синтетический, `r` — только настоящие начертания |
| `<i>`, `<em>` | Курсив | наклон в процентах от высоты глифа |
| `<size>` | Размер | `24`, `150%`, `+10`, `-5`, `1.2em` |
| `<color>` | Цвет | `#RGB`, `#RRGGBB`, `#RRGGBBAA` или имя |
| `<alpha>` | Прозрачность | `0.5`, `50%`, `#80` |
| `<font>` | Семейство | имя семейства из стека шрифтов |
| `<lang>` | Язык | тег BCP 47 |
| `<u>`, `<s>` | Подчёркивание, зачёркивание | необязательный цвет |
| `<outline>` | Контур | цвет, ширина в em или `2px` |
| `<shadow>` | Тень | цвет, x, y, мягкость, расширение |
| `<ellipsis>`, `<truncate>` | Сокращение диапазона | позиция: 0 начало, 0.5 середина, 1 конец |
| `<dir>` | Базовое направление | `ltr`, `rtl`, `auto` |
| `<br>` | Перенос строки | |
| `<noparse>` | Содержимое без разбора | |

`\<` экранирует разметку. Параметры разделяются запятыми, значения можно брать в кавычки: `<shadow=#000,0.1,-0.1>`.

Свой тег — это стиль в тексте или пресете:

```csharp
label.Styles.Add(LetteraStyle.ForTag(new ColorEffect(), "warning", "#FF8800"));
label.MarkStylesDirty();
```

Собственное поведение наследуется от `LetteraEffect` (как выглядит диапазон) и `LetteraMatcher` (как диапазоны находятся).

### Web

Браузеры не дают доступа к файлам шрифтов, поэтому на web:

- Текст без шрифта использует встроенный Noto Sans: латиница, кириллица и греческий. **Остальные письменности показывают квадраты, пока вы не назначите шрифт**, который их покрывает, через **Font** или **Font Stack**. После этого шейпинг работает как везде.
- Эмодзи рисует Canvas браузера, поэтому они выглядят как эмодзи этого устройства. Цвет и прозрачность применяются как обычно.
- `LetteraSettings.WebGLFallbackFont` заменяет встроенный шрифт.
- Память под глифы ограничена сильнее, чем на других платформах: при достижении лимита используется заново страница атласа, к которой дольше всего не обращались.

## Пересборка нативного плагина

`Native~/build.py` собирает HarfBuzz и обёртку на C для всех платформ с помощью [zig](https://ziglang.org), а Android — с помощью NDK из модуля Android в Unity. Шейпинг выполняет [HarfBuzz](https://harfbuzz.github.io), собранный из исходников в `Native~/third_party`; см. [сторонние лицензии](THIRD-PARTY-NOTICES.md). В библиотеках для iOS и web символы HarfBuzz переименованы, потому что плеер Unity сам содержит его копию.
